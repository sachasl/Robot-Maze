# Java Robot Maze Controller

A Java-based autonomous robot controller developed as part of my Computer Science coursework.

## Overview

The controller enables a robot to autonomously explore and solve unknown mazes. It makes navigation decisions based on its surroundings and records information about its route to support backtracking and subsequent maze runs.

## Features

- Autonomous maze exploration
- Detection and handling of corridors, junctions, crossroads and dead ends
- Stack-based backtracking
- Records junction and route information
- Switches between exploration and backtracking modes
- Replays a previously discovered solution path
- Uses object-oriented Java design

## Concepts Demonstrated

- Java
- Object-Oriented Programming
- Arrays and data structures
- Stack-based algorithms
- Search and backtracking
- Control flow and decision making
- Algorithm design
